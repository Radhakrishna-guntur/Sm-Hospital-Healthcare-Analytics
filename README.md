# Project Overview

This project implements a complete machine learning pipeline to predict hospital readmissions
within 30 days for diabetic patients. By analyzing data from 130 US hospitals over 10 years
(1999–2008), the system supports healthcare providers in identifying high-risk patients, reducing
readmission rates, and improving overall patient outcomes.

# Key Objectives

**Predictive Analytics:** Forecast readmission probability.
**Risk Stratification:** Identify key risk factors.
**Healthcare Optimization:** Improve resource allocation.
**Clinical Support:** Actionable insights for clinicians.
